Chatbot Conversacional con IA

Integración de Telegram + Gemini + Groq

Sobre el proyecto

Este proyecto integra un bot conversacional de Telegram con dos modelos de inteligencia artificial distintos: Google Gemini y Groq (Llama 3.3). El asistente responde preguntas de forma natural en tiempo real, tanto desde Telegram como desde esta página web.

Tecnologías utilizadas

  • Python + Flask
  • pyTelegramBotAPI
  • Google Gemini API
  • Groq API
  • Render (despliegue en producción)
